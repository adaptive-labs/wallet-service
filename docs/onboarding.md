# Getting started with Wallet Service

Welcome to `wallet-service`. This guide gets you from zero to a running local copy.

## Prerequisites

- Docker
- Access to the adaptive-labs GitHub org

## Run locally

```bash
git clone git@github.com:adaptive-labs/wallet-service.git
cd wallet-service && make dev
```

## First task

Pick a `good-first-issue` and ship a small change end to end.
